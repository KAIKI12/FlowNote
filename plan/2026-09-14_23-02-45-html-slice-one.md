# HTML Block Slice 1

目标：Markdown A → 显式插入 HTML → Markdown B → 保存 `.note` → 关闭 → 重开，位置、Current / Original 和 Block 配置保持；原 `.md` 不受损。

前提：用户已明确确认真实输入法、原生文件选择器、界面操作和 Markdown Gate 通过，决策记录为 PASS WITH PATCHES。继续开发已经授权，按小批次执行；不重复请求常规实现确认。

## 设计和接口

采用 [Format v1](<../FlowNote Note Format v1.1 — Freeze Candidate Draft.md>)：`note.json`、`content.md`、`blocks/<uuid>/block.json`、`index.html`、`original.html`。Anchor 仅序列化 `{ "id": "..." }`，顺序只在 Markdown 中；原始 HTML 在普通编辑中不改变。

现有 Markdown 命令与 FlowNoteEditor API 保持兼容。增加 Note 端口命令 `note_open` / `note_save` / `note_save_as` / `note_reload` / `note_release`。Note 能力 id 使用 `note:` 前缀，仍是不可伪造的随机能力，不是路径。

共享 IPC 数据：

```typescript
type HtmlBlockData = {
  id: string; html: string; originalHtml: string;
  config: { kind: 'html'; inputKind: 'fragment' | 'document';
    scriptPolicy: 'off' | 'sandbox'; viewport: { heightPx: number }; [key: string]: unknown };
};
type MixedNoteData = {
  metadata: { formatVersion: number; type: 'mixed'; title: string;
    createdAt: string; updatedAt: string; [key: string]: unknown };
  blocks: HtmlBlockData[];
};
// Snapshot = existing MarkdownFile fields + mixed: MixedNoteData.
// note_save request = { id, revision, content, mixed }.
// note_save_as request = { name, content, mixed, sourceId? }.
```

普通新建 / 转换可不提供 sourceId；已有 Mixed Note 另存时提供 Note id，以保留目录内已有资源和 Orphan。修改 Existing Block 时拒绝覆盖 Original。无效 / 重复 Anchor、缺失 Block 或未知格式版本保留原内容并显示诊断或只读保护，不能静默补造 HTML。

文件服务使用同目录候选完整快照，复制已有目录时保留安全属性及额外文件，不跟随链接。候选校验、关键文件同步后，再通过无覆盖的目录移名提交。已有目录移入同级唯一恢复位置并保留；失败保留新旧版本，不递归删除用户数据。本切片保留恢复目录，后续再实现回收策略；不宣称单步原子或断电验收。

HTML 仅在显式确认导入后运行。NodeView 使用隔离 iframe，Script Off / Sandbox，默认断网；CSP 与 sandbox 负责限制，扫描只作提示。网络授权仅是当前预览会话状态，源码变化、关闭预览和重开后重置。Parent frame-src 限制及子文档 CSP 一并验证；不得暴露宿主 / Tauri API。

第一次转换使用候选 Markdown（不提前改动当前编辑器），创建 `.note` 成功后才应用；取消或失败保留原笔记和导入草稿。已有 Mixed Note 的 HTML 编辑即时标脏，保存快照包含 HTML / 配置，不仅比较 Markdown；关闭锁也覆盖 HTML 编辑。
