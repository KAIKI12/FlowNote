# Markdown 文件流程实施计划

目标：让普通 .md / .markdown 笔记通过真实文件服务完成打开、编辑、保存与重开；保存失败、外部修改或并发输入不能丢失内容。

设计：Tauri 命令负责原生选择器和有范围限制的文件句柄。Windows 保存使用父目录保护、文件句柄锁、版本核验、同步暂存及无覆盖的句柄重命名；提交间隙出现外部文件时保留外部版本及两份恢复内容。网页明确提供只读导入 / 下载导出；可靠原位保存本轮由桌面版交付。界面通过可注入文件端口协调操作，编辑器 API 签名和 Markdown 磁盘格式保持不变。

2026-09-14：保存改为句柄锁定与无覆盖移名，检查后替换竞争和 ReplaceFileW 部分失败导致丢失的问题已修复。补齐写正文前的 OWNER / GROUP / DACL 及保护标志保留、基础属性和创建时间保留；ADS、多个硬链接及特殊存储属性明确拒绝。原对象移名后及清理恢复副本前再次复核；发现迟到元数据时保留恢复副本。23 项 Rust 真实文件测试通过，审查已完成。不把两步交接称为单步原子替换，不承诺冻结任意已有元数据句柄或保留完整 SACL，也未进行断电恢复验证。

打开先取得候选文件，再处理当前未保存内容；取消或保存失败保留当前笔记。保存按序执行，记录保存时的编辑快照，新输入不能被旧保存回执清除。组合输入期间不替换正文或启动保存。应用关闭和笔记切换均检查实时状态。
