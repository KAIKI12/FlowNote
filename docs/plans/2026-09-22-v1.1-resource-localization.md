# V1.1 Resource Localization Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add explicit user-triggered Make Local support for reusable Visuals so supported static HTTPS dependencies can be stored and previewed offline without rewriting Current/Original source or changing Note Format v1.

**Architecture:** Frontend dependency analysis identifies deterministic static remote references and the runtime resolver consumes `block.json.resources.localized` mappings. A Rust localization engine performs the privileged HTTPS downloads with public-address checks and an atomic staged Visual Library replacement. The existing Visual Library package/insert path copies mappings and localized private assets into a fresh destination Block automatically.

**Tech Stack:** Tauri 2 / Rust, reqwest blocking client with rustls, React 18 / TypeScript, DOMParser, existing Visual Library + Note atomic-save transaction, Node test harness, Rust integration tests.

**Step 1: Write failing Rust tests**

Cover a fake fetcher and real filesystem transaction:

- localize supported dependencies into `assets/localized/**` while leaving `index.html` and `original.html` byte-identical;
- write `resources.localized` entries with source/path/type/mime/sha256;
- resolve relative CSS `url()` against a stylesheet source and store the nested payload;
- preserve an unsupported CSS `@import` as a localization issue;
- failed second download leaves the old item directory/config/assets unchanged;
- reject http, localhost, loopback/private/link-local/unspecified IPs, excessive redirects, oversized bytes and MIME mismatches;
- repeated Make Local is idempotent for already mapped sources.

**Step 2: Verify RED**

Expected: FAIL because the localization engine/API is absent.

Add direct `reqwest` (blocking + rustls) and `regex` dependencies. Implement:

- typed localization request/dependency structures;
- pure URL/public-IP/MIME/limit validation helpers;
- a `RemoteFetcher` trait for deterministic tests;
- production HTTPS fetcher with no redirects/cookies, manual bounded redirects, DNS public-address validation and request pinning;
- staged item copy, downloads, mapping/config update, metadata timestamp update, atomic directory swap + cleanup/recovery;
- CSS `url()` recursion only; `@import` becomes a diagnostic.
