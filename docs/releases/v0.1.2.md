# FlowNote v0.1.2

This release focuses on making the desktop app feel less abstract and more recoverable in daily use.

## What changed

- **Workspace Trash is now real and recoverable.** Markdown files, `.note` packages, and folders move into a Workspace-local hidden Trash instead of being destroyed immediately. The Trash view supports exact-path restore and separately confirmed permanent deletion.
- **File row actions are practical.** The three-dot menu and right-click use the same actions. Folders expose **New Note Here**, Rename, and Move to Trash; notes expose Rename and Move to Trash.
- **Dirty-document safety is preserved.** Moving the active document to Trash still goes through the existing unsaved-changes decision. Cancel means no filesystem move happens.
- **HTML insertion is easier to discover.** The primary action is now **Add Visual**, with direct HTML-source wording. Pasting complete standalone HTML source into the editor also routes to the existing sandboxed HTML Visual / Mixed Note pipeline.
- **Standard LaTeX is back in the visual editor.** `$...$` and `$$...$$` use Milkdown math instead of forcing the whole document into source protection.
- **Blank-canvas editing is improved.** Clicking below or around the current Markdown content focuses the editor and places the caret at the mapped position or document end.

## Resource localization

The **Make Local** resource-localization baseline introduced in v0.1.1 remains integrated and verified with the new Workspace and editor changes. Static HTTPS scripts, stylesheets, images, and supported CSS `url()` dependencies can still be explicitly localized without rewriting Current or Original HTML.

## Known limits

- `\\(...\\)` and `\\[...\\]` LaTeX delimiters still use source protection.
- Workspace Trash does not yet provide bulk empty, custom restore destinations, or automatic retention cleanup.
- Make Local does not yet cover full `@import`, ES module graphs, dynamic `fetch()`, Worker, or WASM dependencies.
- Note-shared `assets/shared/**` deduplication and cross-note managed shared dependency copy remain later work.

## Verification

The integrated v0.1.2 candidate passed the FlowNote format-freeze gate, Stage One, HTML, protection, Workspace, disk, desktop, qualification, Rust, Clippy, and frontend production-build checks before packaging.
