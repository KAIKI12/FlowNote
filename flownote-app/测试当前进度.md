## 启动测试

```bash
cd flownote-app
npm run dev
```

或双击 `启动Web版本.bat`

## 测试步骤

### 1. 查看初始内容
打开应用后，编辑器会加载一个测试笔记，包含：
- 普通 Markdown 内容
- 一个预定义的 HTML Block (html_001)

### 2. 测试 HTML Block 显示
在编辑器中可以看到 HTML Block 的占位符显示：
- 头部显示 "HTML" 标签和 Block ID
- 内容区域显示 "HTML Block: html_001"

### 3. 插入新的 HTML Block
点击左侧边栏的 "➕ 插入 HTML Block" 按钮：
- 会生成一个新的 HTML Block ID
- 插入到编辑器当前光标位置
- 在状态中添加对应的 HTML 内容

### 4. 查看演示页面
点击左侧边栏的 "🔍 演示" 按钮：
- 查看当前 Note 的元数据
- 查看 content.md 的 Markdown 源码
- 查看所有 HTML Blocks 列表
